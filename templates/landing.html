How this is different from a directory

  • Unlike link-only directories, Runcast downloads and keeps the original file — the asset survives even if the source disappears.
  • Instead of a browse-only catalog, Runcast generates both a terminal and a Claude Code command the moment you need it.
  • Ratings, reviews, and a trend score aren't bolted on later — they're built into the data model from day one.
{% else %}

기존 디렉터리와 다른 점

  • 링크만 모아두는 디렉터리와 달리, 원본 파일을 실제로 내려받아 보관합니다 — 출처가 사라져도 자산은 남습니다.
  • 보기만 가능한 카탈로그가 아니라, 터미널/Claude Code 두 버전의 실행 커맨드를 그 자리에서 만들어 줍니다.
  • 평점·후기·트렌드 스코어가 나중에 붙는 기능이 아니라 처음부터 데이터 구조에 들어 있습니다.
